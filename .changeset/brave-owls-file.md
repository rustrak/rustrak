GitHub issues opened from Rustrak start from a draft you can edit: the title, a description with a link back and the latest event in a code block, labels and the assignee's GitHub login. Issue templates set labels, a title prefix and a description footer for the whole instance and for each project, and issues opened automatically use them too. Recent times in the dashboard no longer read as future times (@rookbreezy).
