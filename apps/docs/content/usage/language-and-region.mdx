# Language & Region

The dashboard speaks English, Spanish (Español), French (Français), Romanian (Română) and Simplified Chinese (简体中文). Language, time zone and theme are personal: each person picks their own in **Settings → Preferences**, and language and time zone are saved on their account, so they follow them to any browser.

## Language

Pick one under **Language and region**. It applies at once.

Until someone picks a language, the dashboard follows the one their browser asks for, and falls back to English when it has no translation. Regional variants match their language: any variant of Chinese gets Chinese. The login page and invitation links follow the browser too, since there is no account to read yet.

## Time zone

The time zone decides how every date and time is shown.

- The first time someone opens the dashboard, their browser's zone is saved to their account, but only if they have none yet. A zone they chose is never overwritten.
- The picker is searchable and shows each zone's current UTC offset, so you can type a city or an offset such as `+02`.
- Pick **UTC** to read times the way events record them. Times shown in UTC are labelled as such; times in your own zone are not.

Event and issue times are always stored in UTC. The server's own log lines are in UTC too, unless `RUSTRAK_LOG_TIMEZONE` names another zone for them.

## Theme

**Display** offers **Light**, **Dark** or **System**, which follows your operating system.

## Over the API

`PATCH /auth/me` sets the language and time zone. It takes your dashboard session, not an API token:

```bash
curl -X PATCH -b cookies.txt -H "Content-Type: application/json" \
  -d '{"language": "zh", "timezone": "Asia/Shanghai"}' \
  "$RUSTRAK_URL/auth/me"
```

| Body | Effect |
|---|---|
| `{"language": "zh"}` | Sets the language, leaves the time zone alone |
| `{"language": null}` | Clears it: back to following the browser |
| `{}` | Changes nothing |

Any well-formed language tag and any real time zone name is accepted. A language the dashboard has no translation for falls back like the browser's would.

## Add a language

A new language is one file of translated phrases, with no server change. See [Contributing](/reference/contributing#adding-a-language).
