# Projects

A project is one application you monitor: a web app, an API, a worker. Each has its own DSN, issues, logs and the rest. The [quickstart](/getting-started/quickstart) shows how to create one.

## Create a project

Go to **Projects → New Project**, pick the platform, give it a name and click **Create Project**. The slug is generated from the name; click **Edit slug** to choose your own. Two projects cannot share a slug.

Rustrak then opens **Settings → SDK** with the DSN, the install command and a setup snippet for the platform you picked.

## The DSN

The DSN is the address a Sentry SDK sends to. It holds the project's public key and ID:

```text
http://32159c3edfd340c28869ce39e4faaa48@rustrak.example.com/4
```

The host comes from the server's [`PUBLIC_URL`](/configuration/environment#public_url). Find the DSN any time under the project's **Settings → SDK**.

## Settings

Open a project's settings from **Settings** at the bottom of its sidebar.

| Page | What is there |
|---|---|
| **General** | Name, slug and platform, and **Remove Project** |
| **Members** | Who can see the project, and with which role. See [Team & access](/usage/team) |
| **SDK** | The DSN and the setup snippet |
| **Data** | Which products the project keeps, and its event limits |
| **Repository** | The [GitHub](/configuration/github) repository linked to the project |
| **Alerts** | The project's [alerts](/usage/alerts) |

The slug is in every issue's short ID (`STOREFRONT-1`), so renaming it renames those. The DSN and dashboard links use the numeric ID and keep working.

**Settings → Data → Products** lists what the project keeps: User Feedback, Releases, Performance, Logs, Crons and Agents. Issues are always on. Turning a product off removes it from the sidebar and drops its data as it arrives: the SDK keeps sending, Rustrak stops storing. What is already stored stays and shows again when you turn it back on. Turning Performance off turns Agents off too, since AI spans travel inside performance data.

Drag the products, or use the arrows, to set the order the sidebar lists them in.

## Event limits

**Settings → Data → Event limits** caps how many events the project stores per minute and per hour. Past a limit, Rustrak answers `429` and the SDK waits before sending more. Leave a field empty to use the server's limit, set in **Settings → Instance**; a project's limit can only be lower than the server's. The page also counts the events dropped by a limit.

## Remove a project

**Settings → General → Remove Project** deletes the project with all its issues and events. It cannot be undone.

## One project or several

Make one project per application: the web front end, the API and the mobile app each get their own. Keep environments of the same app in one project and tell them apart with the SDK's `environment` option; every page filters by environment.

```javascript
Sentry.init({
  dsn: 'YOUR_DSN',
  environment: 'production',
});
```
