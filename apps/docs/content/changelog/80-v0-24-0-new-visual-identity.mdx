## A new look

Every dashboard screen now runs on Rustrak's own design system, with a quieter, flatter look.

- Neutral charcoal surfaces in dark mode and a soft neutral light theme
- Inter for text, Hugeicons for icons
- Code and stack traces get their own surface, with syntax colours that follow the theme
- Severity, status and trend colours stay consistent across every screen

## Navigation

- The project switcher moves to the top of the sidebar
- Search in the sidebar is now a field
- The overview gets separate scope filters, and one short note replaces the two empty session cards

## Improvements

- Form errors are announced to screen readers, and invalid fields are focused and outlined
- Tags and column headers use sentence case
