# FAQ

## General

### What SDKs work with Rustrak?

Any Sentry SDK. Rustrak implements the Sentry protocol, so you can use the official Sentry SDKs for JavaScript, Python, Go, Rust, Java, .NET, PHP, Ruby, and more.

### What does Rustrak cover?

- **Errors**: grouping into [issues](/usage/issues), stack traces with [source maps](/usage/source-maps) and [debug files](/usage/debug-files), and [alerts](/usage/alerts)
- **[Performance](/usage/performance)**: transactions and spans
- **[Releases](/usage/releases)**: release health from SDK sessions
- **[Logs](/usage/logs)**, **[Crons](/usage/crons)**, **[user feedback](/usage/user-feedback)** and **[AI agent](/usage/agents) traces**

It does not support session replays or profiling.

### How much resources does Rustrak need?

One container of about 20 MB, dashboard included, that idles under 100 MB of
memory. A 512 MB VPS is enough for a small team. The dashboard is static files,
so it adds nothing under load.

### Can I migrate from Sentry?

Yes: change your DSN. Your SDK code stays the same:

```javascript
// Before
Sentry.init({ dsn: 'https://key@sentry.io/123' });

// After
Sentry.init({ dsn: 'http://key@your-server:8080/1' });
```

Historical data doesn't migrate; you start fresh.

## Deployment

### Do I need to run the dashboard separately?

No. The server serves it at `/`, on the same port as the API, so there is
nothing else to run. Two variations exist for special cases:

- **API only**: set `RUSTRAK_DASHBOARD=off` and the server serves no pages.
- **Dashboard on another host**: run `rustrak/rustrak-ui` there. See
  [Dashboard on its own host](/configuration/production#dashboard-on-its-own-host).

### Can I run Rustrak without Docker?

Yes. Build from source, from the repository root:

```bash
pnpm install
pnpm build --filter=@rustrak/server   # builds the dashboard, then the server
cd apps/server
DATABASE_URL=sqlite://./rustrak.db \
  SOURCEMAP_STORAGE_PATH=./data/sourcemaps \
  ./target/release/rustrak
```

This build uses SQLite. Without `DATABASE_URL` the database goes to
`/data/rustrak.db`, the path the Docker image uses, which a machine without a
writable `/data` cannot create; set it, and `SOURCEMAP_STORAGE_PATH`, to a
local path as above. For PostgreSQL, build with
`cargo build --release --no-default-features --features postgres`. A plain
`cargo build` works too, without Node, and gives a server with no dashboard.

### How do I back up my data?

Back up the database and the source maps. See
[Backups](/configuration/production#backups) for SQLite and PostgreSQL.

## Data

### How long are events stored?

Until you say otherwise: by default everything is kept. An admin sets how long
errors, transactions and logs are kept under **Settings → Storage**, and a
scheduled cleanup deletes what is older. Old data can also be deleted by hand
there. See [Storage](/usage/storage).

### Can I export my data?

Yes, via the API:

```bash
# Get all issues
curl -H "Authorization: Bearer TOKEN" http://localhost:8080/api/projects/1/issues

# Get events for an issue
curl -H "Authorization: Bearer TOKEN" http://localhost:8080/api/projects/1/issues/ISSUE_ID/events
```

### Is my data encrypted?

- **In transit**: Use HTTPS (configure via reverse proxy)
- **At rest**: Depends on your disk or PostgreSQL setup

Rustrak doesn't add additional encryption.

## Troubleshooting

### Why are my errors grouped incorrectly?

Rustrak groups by exception type, message, and transaction. Use custom fingerprints for better control:

```javascript
Sentry.captureException(error, {
  fingerprint: ['my-custom-group'],
});
```

### Why don't I see stack traces?

Check that your SDK is configured to send them. For minified JavaScript,
upload [source maps](/usage/source-maps).

### Can I ignore certain errors?

Use your SDK's `beforeSend` hook:

```javascript
Sentry.init({
  dsn: 'YOUR_DSN',
  beforeSend(event) {
    if (event.message?.includes('Expected error')) {
      return null; // Don't send
    }
    return event;
  },
});
```

Or [archive](/usage/issues#resolve-archive-reopen) the issue in the dashboard.

## Features

### Does Rustrak support alerts?

Yes. New issues, regressions and user feedback can notify Slack, email, a
webhook, or a custom webhook whose JSON body you write, for services with
their own message format.
See [Alerts](/usage/alerts).

### Is there multi-user support?

Yes. Admins invite users and assign roles, and access can be limited per
project. See [Team & Access](/usage/team).

### Is there multi-organization support?

No. Rustrak is designed for single-team use. For multiple organizations, run separate instances.
