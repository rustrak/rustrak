# Mattermost

Mattermost's incoming webhooks accept Slack-formatted payloads, so Rustrak
delivers alerts to Mattermost today through the **Custom webhook** channel.
There is no separate connector to install.

1. In Mattermost, open **Integrations → Incoming Webhooks → Add incoming
   webhook**, pick the channel alerts should land in, and copy the URL.
2. In Rustrak, open **Settings → Integrations → Custom webhook** and fill in:
   - **Name:** `Mattermost`
   - **URL:** the incoming-webhook URL
   - **Start from:** *Slack and compatible*
3. Press **Test** and confirm the message arrives, then save.
4. In each project, create an alert under **Alerts** and choose this channel.

A minimal body works anywhere Mattermost renders Slack text:

```json
{
  "text": "Rustrak: {{ issue.title }} ({{ issue.short_id }})\n{{ issue_url }}"
}
```

Mattermost renders Slack `attachments` but not Slack Block Kit, so keep the
body to `text` and, if you want structure, `attachments` with `title`,
`title_link`, `text` and `color`. The *Slack and compatible* starting point
uses Block Kit, which Mattermost ignores; replace it with the body above if you
want the message visible in older Mattermost versions.

A first-class Mattermost channel (incoming webhook plus per-rule channel,
username and icon, mirroring the Slack provider) is tracked upstream.
