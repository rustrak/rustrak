# Overview

Rustrak is a lightweight, self-hosted error tracking system. It speaks the Sentry protocol, so any Sentry SDK you already use can send to it: change the DSN and you are done.

## Why Rustrak?

- **Self-hosted**: Your data stays on your servers
- **Lightweight**: about 20 MB image, under 100 MB of memory idle
- **Fast**: Under 50ms ingestion latency
- **Simple**: One container, no complex configuration
- **Free**: No per-event pricing, no limits

## How it works

```
Your App → Sentry SDK → Rustrak server → SQLite or PostgreSQL
                         (API + dashboard on :8080)
```

Your application sends errors using any Sentry SDK. Rustrak receives them, groups similar errors into issues, and stores everything in the database. You view and manage issues in the dashboard, which the same server serves.

## Database backends

Rustrak ships two Docker image variants, each compiled for a different database backend. Both include the dashboard.

| Image tag | Backend | Use case |
|-----------|---------|----------|
| `latest`, `vX.Y.Z` | **SQLite** | Personal projects, low traffic, zero-ops setup |
| `postgres`, `vX.Y.Z-postgres` | **PostgreSQL** | Production, teams, high throughput |

SQLite is the default: no external service needed. PostgreSQL is available for deployments that need concurrent writes or high volume.

## Deployment

One container, one port, one process:

```bash
docker run -d -p 8080:8080 \
  -v rustrak_data:/data \
  -e SESSION_SECRET_KEY=$(openssl rand -hex 32) \
  -e CREATE_SUPERUSER=admin@example.com:your-secure-password \
  rustrak/rustrak-server:latest
```

Open **http://localhost:8080** and sign in. The dashboard is compiled to static files and served by the same process that answers `/api`, so there is no second image and no API address to configure. The browser and the API share one origin, which is what keeps the session cookie first-party.

The whole thing idles under 100 MB of memory, which makes it comfortable on:
- a VPS with 512MB–1GB
- edge deployments
- cost-conscious setups

**The dashboard is optional.** Set `RUSTRAK_DASHBOARD=off` and the server answers the API and nothing else. Point any Sentry SDK at it and never open a UI.

## What's included

- Error and exception tracking, with stack traces and source context
- Issue grouping, deduplication and states (open, resolved, muted)
- Source maps for JavaScript, including Hermes and React Native
- Performance: transactions and spans
- Release health and session tracking
- Logs and AI agent traces
- Alerts to Slack, email, webhooks and custom webhooks
- Teams, roles and API tokens
- Storage usage and retention

## What's not included

- Attachments
- Session replays
- Profiling
