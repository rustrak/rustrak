# Quickstart

From a running server to your first issue. You need Rustrak [installed](/getting-started/installation) and the account from `CREATE_SUPERUSER`.

## Create a project

Sign in, then go to **Projects → New Project**. Pick the platform you want to monitor, give the project a name and click **Create Project**.

<InteractiveDemo src="/demos/quickstart.openshowcase" />

Rustrak opens the project's **Settings → SDK** page. It has the DSN, the install command for the platform you picked and a setup snippet with the DSN already filled in. The DSN looks like this:

```text
http://32159c3edfd340c28869ce39e4faaa48@localhost:8080/4
```

If the host in the DSN is `0.0.0.0`, the server has no `PUBLIC_URL`. Set it to the address your applications reach, for example `https://rustrak.example.com`, and restart. See [`PUBLIC_URL`](/configuration/environment#public_url).

## Send an event

Rustrak works with the official Sentry SDKs, so install the one for your language:

```bash
npm install @sentry/node         # Node.js (@sentry/browser in the browser)
pip install sentry-sdk           # Python
go get github.com/getsentry/sentry-go
cargo add sentry                 # Rust
```

Initialize it with your DSN and capture something:

```javascript
import * as Sentry from '@sentry/node';

Sentry.init({ dsn: 'YOUR_DSN' });

Sentry.captureException(new Error('Something went wrong'));
```

```python
import sentry_sdk

sentry_sdk.init(dsn="YOUR_DSN")

try:
    1 / 0
except ZeroDivisionError as e:
    sentry_sdk.capture_exception(e)
```

```go
import (
    "errors"
    "time"

    "github.com/getsentry/sentry-go"
)

sentry.Init(sentry.ClientOptions{Dsn: "YOUR_DSN"})
defer sentry.Flush(2 * time.Second)

sentry.CaptureException(errors.New("something went wrong"))
```

```rust
let _guard = sentry::init("YOUR_DSN");

sentry::capture_message("Something went wrong", sentry::Level::Error);
```

The SDKs send in the background. A script that exits right away can quit before the event leaves: Go needs the `Flush` above, and in Node.js call `await Sentry.flush()` before exiting. Python and Rust flush on exit.

## Find the issue

Open the project in the dashboard. The event shows up as an issue on its **Issues** list, with its stack trace. Events with the same exception type and message land in the same issue, so sending it again raises the count instead of adding a row.

Click **Resolve** on the issue when you have fixed it. If the error happens again, Rustrak reopens it as a regression.
